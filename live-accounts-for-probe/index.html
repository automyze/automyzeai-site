Positioning

Why "another experiment tracker" fails, and where Probe wins.

Tracking runs is the part these teams are already staffing: Noetik's own posting asks a new hire to build experiment tracking and model registry workflows. What a tracker does not hold is what the team already tried, and why, which is what the next agent session starts without.

The Commodity Trap

Pitching "run tracking and dashboards"

Leading with tracking competes with the tools these teams run and with the hire they are trying to make, and it asks the buyer to compare feature lists.

The High-Converting Angle

Positioning as the team's memory for agents

Probe carries a team's decisions and past agent work into every new agent session. In Probe's own early benchmarks, an agent swarm given that shared context reached a best accepted kernel speedup of 50.8x over eager PyTorch, against 34.9x for the same swarm without it (+46%), and a 5.06x inference speedup against 3.49x (+45%). Probe measured those results on its own shared-context data.

What this list does not claim

  • Headcount is self-reported or estimated, not confirmed. Most counts come from the Y Combinator directory (self-reported by the company to YC) or from third-party estimates that disagree with each other. Only Artificial Analysis states its own (40, on its careers page). Every credible figure found sits inside the 3 to 150 envelope; none is company-confirmed.
  • Funding totals come from press coverage and aggregators. Tavus's three press-reported rounds sum to about $64M and one aggregator lists a higher total those rounds do not account for. HUD and Sieve have one aggregator or job-post mention each of a larger round that is unconfirmed. All stay far below the $100M cap on every figure found.
  • A public repository date is not a release. For Krea, Genmo, SF Tensor and AfterQuery it shows a repository was updated or pushed on that date, which can include a model card or a small edit.
  • Some accounts rest on one source type. Noetik's two signals are separate postings on its own Greenhouse board, posted the same day. That is two requisitions, not two independent source types.
  • Personas are role titles. No named individual was verified for any account; confirm the right person before outreach.

Clusters

Three ways a research team shows its context is about to be stretched.

An account enters this dispatch only when two independent public facts agree. We pull the live source for each, keep a dated copy, and confirm the quoted text is physically in that copy before drafting a single word.

CLUSTER 01

Coding Agents Already In The Research Repos

A public repository carries an AGENTS.md or CLAUDE.md with a recent commit, and the same company has research seats open or says it is growing. Agents are already working on the code; the question is what they know about past experiments.

Verifiable Signals
  • AGENTS.md or CLAUDE.md committed to a public repository in the last 60 days
  • Research seats open on the company's own applicant tracking system or careers page
  • Commit date and file path readable from the public GitHub API
Probe angle: an instruction file holds rules, not history. Shared team context gives each new agent session the earlier experiments before it starts.
CLUSTER 02

Research Seats Opening, Or The Research Layer Being Built

Researcher seats were posted in the last 60 days alongside public model activity, or a posting asks a new hire to build experiment tracking and reproducibility workflows. Either way the research process is being staffed now.

Verifiable Signals
  • Researcher or research engineer seats posted in the last 60 days on the company's own board
  • A Hugging Face repository updated in the same window
  • Posting text naming experiment tracking, model registry, or reproducibility workflows
Probe angle: the first weeks of a new researcher are spent rebuilding what the team already learned. Shared context shortens that.
CLUSTER 03

A Fresh Round With ML Seats Already Open

The company announced a funding round in the last 60 days on its own site, and ML seats were already posted on its own applicant tracking system. The money arrives behind a hiring plan that is already moving.

Verifiable Signals
  • A funding announcement dated in the last 60 days on the company's own site or press release
  • ML or research seats posted on the company's own applicant tracking system around the same time
Probe angle: a team that has just raised and is hiring ML staff is adding people and agents to the same history.
